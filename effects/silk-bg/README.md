# `silk-bg` — 흐르는 셰이더 그라디언트 배경

> **티어 T2** · 추가 용량 **약 8KB**(OGL, 지연 로드) · WebGL 필요 · **폴백 항상 보장**

히어로 섹션 배경이 비단처럼 천천히 흐릅니다.
포트폴리오에서 "이 사람 좀 하네" 소리를 가장 싸게 얻는 효과입니다.

---

## 1. 붙이기 — 바닐라

```html
<link rel="stylesheet" href="./effects/_core/core.css" />
<link rel="stylesheet" href="./effects/silk-bg/style.css" />

<!-- .fx-silk 는 필수 (폴백 그라디언트가 여기 들어 있습니다) -->
<section class="hero fx-silk fx-silk--scrim fx-silk-hero">
  <div>
    <h1>프론트엔드 개발자<br />김하늘</h1>
    <p>React · TypeScript · 인터랙션 디자인</p>
  </div>
</section>

<script type="module">
  import { mount } from './effects/silk-bg/index.js';
  mount('.hero', { colors: ['#0f172a', '#3b82f6', '#22d3ee'] });
</script>
```

## 2. 붙이기 — React

```jsx
import { SilkBackground } from './effects/silk-bg/react.jsx';

<SilkBackground
  className="fx-silk-hero"
  scrim
  colors={['#0f172a', '#3b82f6', '#22d3ee']}
>
  <h1>프론트엔드 개발자 김하늘</h1>
</SilkBackground>
```

---

## 3. 왜 three.js가 아니라 OGL인가

이 효과에 필요한 건 **전체 화면 삼각형 하나 + 프래그먼트 셰이더**뿐입니다.

| | gzip 용량 | 이 효과에 필요한 것 |
|---|---|---|
| three.js | 약 **150KB** | 씬 그래프·조명·머티리얼·로더 전부 딸려옴 |
| **OGL** | 약 **8KB** | 딱 필요한 만큼 |

**같은 결과에 1/18 용량입니다.**
진짜 3D 모델이 필요해질 때만 three로 올라가세요 → [`model-showcase`](../model-showcase/README.md)

그리고 **지연 로드**입니다. 이 효과를 마운트하는 순간에만 8KB 요청이 나갑니다.
다른 페이지는 한 바이트도 내지 않습니다.

## 4. 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `colors` | `null` | `['#색1','#색2','#색3']`. **`null`이면 CSS 변수 `--fx-silk-c1~c3`에서 읽습니다** |
| `speed` | `0.12` | 흐르는 속도. **0.08~0.18이 "배경"답고 0.3 넘으면 시선을 뺏습니다** |
| `scale` | `2.2` | 무늬 크기. 작을수록 크고 완만한 덩어리 |
| `swirl` | `3.2` | 도메인 워핑 강도. **이게 "비단결"을 만듭니다. 0이면 그냥 구름** |
| `grain` | `0.035` | 그레인 세기. 밴딩 제거용 |
| `mouse` | `true` | 마우스로 무늬 밀기 |
| `mouseStrength` | `0.18` | 마우스 영향 강도 |
| `alpha` | `1` | 1 미만이면 뒤 배경과 섞입니다 |
| `dpr` | `1.25` | 렌더 해상도 배율 상한 |
| `fps` | `0` | 프레임 상한. 0이면 저사양 기기에서 자동 30fps |

### 색은 한 곳에서만 관리하세요

`colors` 옵션을 주면 JS가 **CSS 변수에도 같은 색을 써 넣습니다.**
그래서 셰이더와 폴백 그라디언트가 항상 같은 색입니다.

CSS만으로 색을 정하고 싶으면 옵션을 비우고:

```css
.hero { --fx-silk-c1: #0b1020; --fx-silk-c2: #2563eb; --fx-silk-c3: #7dd3fc; }
```

## 5. 3중 안전망 — 절대 빈 화면이 안 됩니다

| 상황 | 결과 |
|---|---|
| WebGL 미지원 / 동작 줄이기 | 마운트되지 않음 → **CSS 그라디언트가 그대로** |
| OGL 로드 실패 (CDN 차단·사내망·오프라인) | 캔버스 제거 → **CSS 그라디언트가 그대로** |
| WebGL 컨텍스트 손실 (GPU 드라이버 재시작 등) | 캔버스 페이드아웃 → **CSS 그라디언트가 드러남**, 복구되면 자동 재개 |

**폴백 그라디언트는 `.fx-silk` 클래스에 항상 깔려 있습니다.** 캔버스는 그 위에 얹힐 뿐입니다.
그래서 어떤 실패 경로에서도 히어로가 까맣게 비지 않습니다.

> 컨텍스트 손실은 이론적인 얘기가 아닙니다. 탭을 오래 켜두거나 다른 프로그램이
> GPU를 많이 쓰면 실제로 일어납니다. 처리하지 않은 셰이더 배경은 **영구히 까맣게 남습니다.**

## 6. 성능 노트

| 처리 | 효과 |
|---|---|
| `dpr` 상한 1.25 | 배경 그라디언트는 디테일이 없어 눈으로 차이가 안 납니다. 2로 올리면 픽셀 수가 **2.5배** |
| `antialias: false` | 전체 화면 그라디언트에 안티에일리어싱은 무의미 |
| `powerPreference: 'low-power'` | 배경 때문에 노트북 외장 GPU를 깨우지 않습니다 |
| 화면 밖 → 루프 완전 정지 | 스크롤해서 지나가면 GPU 사용률 0 |
| 저사양 기기 30fps 자동 | 배경은 30fps로도 충분히 부드럽습니다 |
| 값 노이즈 (심플렉스 아님) | 5옥타브 × 도메인 워핑이면 모바일에서 차이가 큽니다 |
| 컨텍스트 명시적 반납 | 브라우저당 WebGL 컨텍스트는 8~16개 한도. SPA 라우팅에서 금방 걸립니다 |

## 7. 가독성 — 반드시 읽어야 할 부분

**그라디언트 배경 위의 흰 글씨는 밝은 프레임에서 안 읽힙니다.**
무늬가 계속 움직이므로 "지금은 괜찮아 보여도" 3초 뒤에 안 읽힐 수 있습니다.

```html
<section class="hero fx-silk fx-silk--scrim">  <!-- 어두운 오버레이 -->
<section class="hero fx-silk fx-silk--scrim-light">  <!-- 밝은 오버레이 -->
```

한 겹 깔면 어느 프레임에서도 대비가 유지됩니다.
**이거 안 하면 채용담당자가 이름을 못 읽습니다.**

## 8. 색 조합 레시피

```js
// 딥 블루 (가장 안전, 어떤 포폴에도 어울림)
{ colors: ['#0f172a', '#3b82f6', '#22d3ee'] }

// 바이올렛 (기본값)
{ colors: ['#1b1d3a', '#5b5bd6', '#a78bfa'] }

// 선셋
{ colors: ['#2a1120', '#e0533d', '#f7b955'] }

// 모노톤 (텍스트 가독성 최고)
{ colors: ['#0a0a0a', '#3f3f46', '#a1a1aa'], swirl: 4.5 }

// 민트
{ colors: ['#08201c', '#10b981', '#a7f3d0'] }
```

> **채도가 높은 색 3개는 피하세요.** 어두운 색 1개 + 중간 1개 + 밝은 액센트 1개 조합이
> 텍스트 가독성과 고급스러움을 동시에 잡습니다.

## 9. 셰이더 직접 고치기

`shader.js`의 `FRAG`만 바꾸면 완전히 다른 배경이 됩니다.
로직(`index.js`)은 건드릴 필요가 없습니다.

- `uSwirl`을 `0`으로 → 도메인 워핑 없는 구름
- `fbm`의 옥타브(`i < 5`)를 `3`으로 → 더 부드럽고 더 빠름
- `p *= 2.02`의 `2.02`를 `1.7`로 → 더 유기적인 결

> `2.02`가 `2.0`이 아닌 건 실수가 아닙니다. 정확히 2배씩 키우면 옥타브 격자가
> 정렬돼서 규칙적인 무늬가 눈에 보입니다.

## 10. 자주 겪는 문제

**Q. 배경이 안 보입니다(단색만).**
→ 폴백 그라디언트가 보이는 상태입니다. 콘솔에 `[fx:silk-bg]` 경고가 있는지,
요소에 `data-fx-skipped="no-webgl"`이 있는지 확인하세요.

**Q. 콘텐츠가 캔버스 뒤에 숨습니다.**
→ `.fx-silk > *`에 `z-index: 1`이 걸려 있습니다. 콘텐츠가 `.fx-silk`의 **직계 자식**인지 확인하세요.

**Q. 높이가 0입니다.**
→ 캔버스는 `absolute`라 높이를 만들지 못합니다. 컨테이너에 `min-height`가 필요합니다
(`.fx-silk-hero`에 이미 들어 있습니다).

**Q. 노트북 팬이 돕니다.**
→ `fps: 30`, `dpr: 1`로 낮추세요. 배경으로는 차이를 못 느낍니다.

**Q. 페이지를 옮겨 다니면 배경이 안 뜹니다(React SPA).**
→ WebGL 컨텍스트 한도(8~16개)에 걸린 것입니다. `destroy`가 제대로 불리는지 확인하세요.
`useSilk`/`<SilkBackground>`를 쓰면 언마운트 시 컨텍스트를 명시적으로 반납합니다.

**Q. 그라디언트에 줄무늬(밴딩)가 보입니다.**
→ `grain`을 `0.05`까지 올리세요. 8비트 컬러의 한계를 노이즈로 가리는 표준 기법입니다.
